# Ernest 0.2.0

The pages `ern doc` wrote at the release of Ernest 0.2.0, which `main` may have gone past. A page holds a module's doc block, then its declarations, each with its type and its own doc block (report §11.4). Where Ernest is installed, `man Ernest.List` shows a module's page and `man ern` the toolchain's.
