# Ernest module Ets

*Since 0.1.0.*

Tables of the runtime, keyed by a value of type `k`. A table belongs to
the process that made it and dies with it, or with `close`, and every
operation on a table that is gone faults. Any process on the node that
holds a table reads and writes it: a table is state that processes share,
which is why this is a library and not the standard library's (report
§10). Keys are compared as the runtime compares its terms. Appendix D of
the report shows this library, with a shorter documentation, as its
example of a shim. A program puts the library on its load path, when it
is compiled and when it is run.

## Examples

```ernest
{
    let t = Ets.new();
    Ets.put(t, "a", 1);
    Ets.get(t, "a")
}
// => Some(1)
```

```ernest
{
    let t = Ets.new();
    Ets.put(t, 1, "one");
    Ets.remove(t, 1);
    #(Ets.contains(t, 1), Ets.size(t))
}
// => #(false, 0)
```

## Ets.Table

### Examples
