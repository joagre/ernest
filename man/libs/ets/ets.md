# Ernest module Ets

*Since 0.1.0.*

Tables of the runtime, keyed by a value of type `k`. A table belongs to
the process that made it and ends with it, or with `close`, and every
operation on a table that has ended faults. Any process on the node that
holds a table reads and writes it: a table is state that processes share,
which is why this is a library and not the standard library's (report
§10). Keys are compared as the runtime compares its terms. Appendix D of
the report shows this library, with a shorter documentation, as its
example of a shim. A program puts the library on its load path, when it
is compiled and when it is run.

## Examples

```ernest
{
    let table = Ets.new();
    Ets.put(table, "a", 1);
    Ets.get(table, "a")
}
// => Some(1)
```

```ernest
{
    let table = Ets.new();
    Ets.put(table, 1, "one");
    Ets.remove(table, 1);
    #(Ets.contains(table, 1), Ets.size(table))
}
// => #(false, 0)
```

## Ets.Table

```ernest
foreign type Table(k=, v)
```

A table of the runtime, keyed by `k` with values of type `v`.

### Examples

```ernest
{
    let table : Ets.Table(String, Int) = Ets.new();
```


## Ets.close

```ernest
Ets.close(table : Table(k=!, v!)) : Unit with m+
```

Closes the table, deleting it; every operation on it after this faults.

### Errors

On a table that has ended, faults as a foreign function that raises
does (report §7.4).

### Examples

```ernest
{
    let table = Ets.new();
    Ets.put(table, "k", "v");
```
