# Ernest module Ansi

*Since 0.2.0.*

Text that styles what a program writes to a terminal and moves its
cursor: ECMA-48's control sequences, the standard a terminal speaks,
as strings a program writes with `Io.print` (report Appendix G.3). The
terminal's keys, its size and the columns a string takes there are
`Terminal`'s (report Appendix E.16).

## Examples

```ernest
Ansi.styled("warning", Ansi.Bold) <> Ansi.clearBelow
// => "\u{1B}[1mwarning\u{1B}[22m\u{1B}[J"
```

## See also

`Terminal.columns` for the columns styled text takes, `Io.print` to
write it.

## Ansi.Style

```ernest
type Style = Bold | Dim | Italic | Underline | Foreground(Colour)
```

How text is drawn: its weight, its slant, a line under it, or its
colour.

### Examples

```ernest
Ansi.styled("warning", Ansi.Bold)
// => "\u{1B}[1mwarning\u{1B}[22m"
```

## Ansi.styled

```ernest
Ansi.styled(text : String, style : Style) : String
```

The text in the style, turned off after it with the code that turns off
every style of its kind: `Bold` and `Dim` are one kind, `Italic` one,
`Underline` one, and the colours one. A style of another kind around the
text stays on; one of the same kind is turned off with it, a colour
around a colour, italics around italics, `Bold` around `Dim`.

### Examples

```ernest
Ansi.styled("fault", Ansi.Foreground(Ansi.Red))
// => "\u{1B}[31mfault\u{1B}[39m"
```
