# Ernest module Random

*Since 0.1.0.*

Pseudo-random numbers, drawn from a seed the program carries.

Use it for numbers that need only look random: a shuffle, a simulation, a
test's cases. It is not for secrets: its generator, SplitMix64, is not
cryptographic, and its draws can be predicted from earlier ones.

**A seed is carried.** `seed` makes a `Seed` from a number, and each draw
answers a number and the seed to draw with next. There is no hidden state
and no process, so every function here is pure (report Appendix E.13), and
the same seed gives the same sequence on every node and every version. A
program that wants a sequence that differs between runs seeds from
`Clock.now()`.

## Examples

Two throws of a die, the seed the first answers carried to the second:

```ernest
{
    let #(first, seed1) = Random.next(Random.seed(2026), 5);
    let #(second, _) = Random.next(seed1, 5);
    #(first + 1, second + 1)
}
// => #(2, 6)
```

The same seed draws the same number:

```ernest
Random.next(Random.seed(42), 100) == Random.next(Random.seed(42), 100)
// => true
```

## See also

`Clock.now` for a seed that differs between runs.

## Random.Seed

```ernest
abstract type Seed
```

The generator's state, which a draw takes and gives back. It is a value like
any other, which can be stored, compared and sent to another node.

### Examples

```ernest
Random.next(Random.seed(42), 100) == Random.next(Random.seed(42), 100)
// => true
```

## Random.seed

```ernest
Random.seed(int : Int) : Seed
```

The seed `int` names. The same number gives the same sequence, and so do two
numbers equal in their low 64 bits.

## Random.next

```ernest
Random.next(seed : Seed, bound : Int) : #(Int, Seed)
```

A number from 0 to `bound`, both included, and the seed to draw with next. A
negative `bound` draws from `bound` to 0, and a `bound` of 0 always draws 0.
Every number in the range is equally likely.

### Examples

```ernest
{
    let #(x, _) = Random.next(Random.seed(1), -3);
    x <= 0 && x >= -3
}
// => true
```

## Random.nextFloat

```ernest
Random.nextFloat(seed : Seed) : #(Float, Seed)
```

A number above 0.0 and below 1.0, and the seed to draw with next. It never
draws 0.0 or 1.0, and its draws are evenly spaced, 2^-52 apart.

### Examples

```ernest
{
    let #(x, _) = Random.nextFloat(Random.seed(3));
    x > 0.0 && x < 1.0
}
// => true
```
