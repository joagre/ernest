# Ernest module Random

*Since 0.1.0.*

Pseudo-random numbers behind a pure interface (report Appendix E.13).
The generator is SplitMix64, written here over `Int`'s bit operations, so
the same seed gives the same sequence on every node and every version. A
`Seed` is made by `seed` and carried from one draw to the next; there is
no hidden state and no process. A program that wants a fresh sequence
seeds from `Clock.now()`.

## Examples

```ernest
let #(die, _) = Random.next(Random.seed(42), 5);
die >= 0 && die <= 5
// => true
```

```ernest
let #(x, _) = Random.next(Random.seed(7), 0);
x
// => 0
```

## See also

`Clock.now` for a seed that differs between runs, `List.sort` for a
shuffle written with draws.

## Random.Seed

```ernest
abstract type Seed
```

The generator's state, which a draw takes and gives back: SplitMix64's
64-bit counter, a value like any other, which crosses nodes.

### Examples

```ernest
Random.next(Random.seed(42), 100) == Random.next(Random.seed(42), 100)
// => true
```

## Random.seed

```ernest
Random.seed : (Int) -> Seed
```

The seed that number names; the same number gives the same sequence, and
so do two numbers equal in their low 64 bits.

## Random.next

```ernest
Random.next : (Seed, Int) -> #(Int, Seed)
```

A number between 0 and the bound, both included, and the seed to draw
with next; a negative bound draws between it and 0. Every number in the
range is equally likely, the draws that would favour some being drawn
again.

### Examples

```ernest
let #(x, _) = Random.next(Random.seed(1), -3);
x <= 0 && x >= -3
// => true
```

## Random.nextFloat

```ernest
Random.nextFloat : (Seed) -> #(Float, Seed)
```

A number above 0.0 and below 1.0, and the seed to draw with next: the
draw's top 52 bits and a half, as a fraction of 2^52.

### Examples

```ernest
let #(x, _) = Random.nextFloat(Random.seed(3));
x > 0.0 && x < 1.0
// => true
```
