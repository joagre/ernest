# Ernest module Erl

*Since 0.1.0.*

What a shim over an Erlang API needs from Erlang's conventions: an atom
made from text. An API that answers `{ok, V}` or `{error, R}` needs an
Erlang helper that rewrites the answer to `Either`'s encoding,
`{'Right', V}` or `{'Left', R}` (report §8.4).

## Examples

```ernest
#(Erl.atom("ready") == Erl.atom("ready"), Foreign.toBool(Erl.atom("true")))
// => #(true, Some(true))
```

## Erl.atom

```ernest
Erl.atom(text : String) : Foreign.Term
```

The Erlang atom of the text. An atom is never freed while the node
lives, and a node holds at most a number of them its host fixes, so it
is made of the names a shim needs, never of text a program receives.

### Errors

A text longer than 255 characters, which no atom holds, faults as a
foreign function's raise does (report §7.4).
