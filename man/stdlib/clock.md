# Ernest module Clock

*Since 0.1.0.*

The time, and alarms.

`now` is the time of day, in milliseconds since the epoch, 1970-01-01 UTC.
`monotonic` is the clock to measure a duration by, since `now` moves when
the host's clock is set. `alarm` and `alarmAt` put a message in the caller's
mailbox later.

**Alarms.** An alarm fires once, and cannot be cancelled: a process that no
longer wants it ignores its message. A periodic tick is set again each time
the one before is handled. A restart of the process that set an alarm
cancels it (report §6.9).

**It needs a process.** The clock is a system process of the runtime (report
§8.2): every function here carries a mailbox effect, `with m`, and is called
from a process, not from a pure function.

## Examples

The time now, in milliseconds since the epoch:

```ernest
Clock.now() > 0
// => true
```

## Clock.now

```ernest
Clock.now() : Int with m+
```

The time now, in milliseconds since the epoch, 1970-01-01 UTC. It moves when
the host's clock is set; `monotonic` measures a duration.

## Clock.monotonic

```ernest
Clock.monotonic() : Int with m+
```

Milliseconds since a moment the runtime chose, which never go back, so the
difference of two readings is the time the host ran between them. Its value
alone says nothing, and `now` is the time of day. Where the host's monotonic
clock stops while the machine is suspended, that time is left out.

### Examples

```ernest
{
    let start = Clock.monotonic();
    Clock.monotonic() - start >= 0
}
// => true
```

## Clock.alarm

```ernest
Clock.alarm(ms : Int, wrap : (Int) -> m) : Unit with m
```

Puts `wrap(time)` in the caller's mailbox after `ms` milliseconds, `time`
the time it fired. A constructor of one argument passes as `wrap` as it is:
`Clock.alarm(100, Tick)` for `Tick(Int)`.

### Examples

```ernest
Clock.alarm(10, fn(_) = Unit)
```

## Clock.alarmAt

```ernest
Clock.alarmAt(time : Int, wrap : (Int) -> m) : Unit with m
```

Puts `wrap(time)` in the caller's mailbox at `time`, in milliseconds since
the epoch, `time` then the time it fired. A time already past fires at once.

### Examples

```ernest
Clock.alarmAt(Clock.now() + 10, fn(_) = Unit)
```
