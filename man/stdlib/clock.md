# Ernest module Clock

*Since 0.1.0.*

Time from the clock, the system process that keeps it (report §8.2).
Times are milliseconds since the epoch; `monotonic` is the clock to
measure a duration by, since `now` moves when the clock is set. An
alarm fires once, and a program cannot cancel it: a process that no
longer wants it ignores the message, and a periodic tick is scheduled
again after the previous one is handled. A restart of the process that
set it cancels it (report §6.9).

## Examples

```ernest
Clock.now() > 0
// => true
```

`Random.seed` for a sequence that differs between runs.

## Clock.now

```ernest
Clock.now() : Int with m+
```

The time now.

## Clock.monotonic

```ernest
Clock.monotonic() : Int with m+
```

Milliseconds since a moment the runtime chose, which never go back, so
that the difference of two readings is the time the host ran between
them; where the host's monotonic clock stops while the machine is
suspended, that time is left out. Its value alone says nothing; `now` is
the time of day.

### Examples

```ernest
{
    let start = Clock.monotonic();
    Clock.monotonic() - start >= 0
}
// => true
```

## Clock.alarm

```ernest
Clock.alarm(ms : Int, wrap : (Int) -> m) : Unit with m
```

After that many milliseconds, `wrap(time)` arrives in the caller's
mailbox, `time` the time it fired. A single-positional constructor passes as
`wrap` directly, `Clock.alarm(100, Tick)` for `Tick(Int)`.

### Examples

```ernest
Clock.alarm(10, fn(_) = Unit)
```

## Clock.alarmAt

```ernest
Clock.alarmAt(time : Int, wrap : (Int) -> m) : Unit with m
```

At that time, `wrap(time)` arrives in the caller's mailbox, `time` the
time it fired; a time already past arrives at once.

### Examples

```ernest
Clock.alarmAt(Clock.now() + 10, fn(_) = Unit)
```
