# Ernest module Char

*Since 0.1.0.*

Characters: one Unicode scalar value each.

A `Char` is written `'a'`. Text is a `String`, and `String.toList` gives its
`Char`s. A letter a reader sees may be several `Char`s, a letter and an
accent, so text is searched and counted as a `String`, not a `Char` at a
time.

The predicates, `isAlpha`, `isDigit`, `isSpace` and the rest, read Unicode's
properties of the character, so they hold for the letters and digits of
every script. `isAsciiDigit` holds for `0` to `9` alone. `<` on two `Char`s
compares their code points.

## Examples

Asking what a character is, and its upper case:

```ernest
#(Char.isDigit('7'), Char.isAlpha('中'), Char.toUpper('é'))
// => #(true, true, 'É')
```

A character's code point, and back; a surrogate is no character:

```ernest
#(Char.toInt('A'), Char.fromInt(66), Char.fromInt(0xD800))
// => #(65, Some('B'), None)
```

## Char.isDigit

```ernest
Char.isDigit(char : Char) : Bool
```

`true` for a decimal digit of any script, Unicode's category Nd.
`isAsciiDigit` holds for `0` to `9` alone.

## Char.isAsciiDigit

```ernest
Char.isAsciiDigit(char : Char) : Bool
```

`true` for one of the digits `0` to `9`, those `String.toInt` reads.

### Examples

```ernest
#(Char.isAsciiDigit('7'), Char.isAsciiDigit('٣'), Char.isDigit('٣'))
// => #(true, false, true)
```

## Char.digitValue

```ernest
Char.digitValue(char : Char, base : Int) : Optional(Int)
```

*Since 0.3.0.*

The character's value as a digit in the base, 2 to 36: `0` to `9`, then
a letter in either case, `a` and `A` 10 to `z` and `Z` 35, the digits
`Int.toStringBase` writes and `String.toIntBase` reads. `None` for a
character that is no digit of the base, and for a base outside 2 to 36.

### Examples

```ernest
#(Char.digitValue('7', 10), Char.digitValue('F', 16), Char.digitValue('9', 8))
// => #(Some(7), Some(15), None)
```

## Char.isAlpha

```ernest
Char.isAlpha(char : Char) : Bool
```

`true` for a letter of any script, Unicode's category L.

## Char.isSpace

```ernest
Char.isSpace(char : Char) : Bool
```

`true` for whitespace, Unicode's White_Space property: a space, a tab, a
line end, and the wider spaces of other scripts.

### Examples

```ernest
#(Char.isSpace('\n'), Char.isSpace('a'))
// => #(true, false)
```

## Char.isUpper

```ernest
Char.isUpper(char : Char) : Bool
```

`true` for an upper-case letter, Unicode's category Lu.

### Examples

```ernest
#(Char.isUpper('A'), Char.isLower('A'))
// => #(true, false)
```

## Char.isLower

```ernest
Char.isLower(char : Char) : Bool
```

`true` for a lower-case letter, Unicode's category Ll.

## Char.toUpper

```ernest
Char.toUpper(char : Char) : Char
```

The upper-case form, or `char` itself where it has no single upper-case
`Char`: `'ß'` stays `'ß'`, since its upper case is two letters, which
`String.toUpper` gives.

## Char.toLower

```ernest
Char.toLower(char : Char) : Char
```

The lower-case form, or `char` itself where it has no single lower-case
`Char`.

### Examples

```ernest
Char.toLower('A')
// => 'a'
```

## Char.toString

```ernest
Char.toString(char : Char) : String
```

The string of that one character.

### Examples

```ernest
Char.toString('é')
// => "é"
```

## Char.toInt

```ernest
Char.toInt(char : Char) : Int
```

The character's code point.

## Char.fromInt

```ernest
Char.fromInt(code : Int) : Optional(Char)
```

The character with code point `code`, or `None` outside U+0000 to U+10FFFF
and for a surrogate, U+D800 to U+DFFF.

## Char.compare

```ernest
Char.compare(left : Char, right : Char) : Ordering
```

Compares two characters by their code points, the order `<` and the other
comparisons use.

### Examples

```ernest
Char.compare('b', 'a')
// => Greater
```
