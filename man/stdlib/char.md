# Ernest module Char

*Since 0.1.0.*

Operations on `Char`, a Unicode scalar value (report §3.1). The predicates
use the code point's Unicode properties; the ordering is the prelude's
(report §9.6), by code point.

## Examples

```ernest
#(Char.isDigit('7'), Char.isAlpha('中'), Char.toUpper('é'))
// => #(true, true, 'É')
```

```ernest
#(Char.toInt('A'), Char.fromInt(66), Char.fromInt(0xD800))
// => #(65, Some('B'), None)
```

```ernest
Char.isDigit : (Char) -> Bool
```

## Char.isAlpha

```ernest
Char.isAlpha : (Char) -> Bool
```

`true` for a letter in any script, general category L.

## Char.isSpace

```ernest
Char.isSpace : (Char) -> Bool
```

`true` for white space, the White_Space property: `' '`, `'\n'`, and the
wider spaces of other scripts.

### Examples

```ernest
#(Char.isSpace('\n'), Char.isSpace('a'))
// => #(true, false)
```

```ernest
Char.isUpper : (Char) -> Bool
```

## Char.toUpper

```ernest
Char.toUpper : (Char) -> Char
```

The upper-case form, or `c` itself when it has no single upper-case
form: `'ß'` stays `'ß'`.

## Char.toLower

```ernest
Char.toLower : (Char) -> Char
```

The lower-case form, or `c` itself when it has no single lower-case form.

### Examples

```ernest
Char.toLower('A')
// => 'a'
```

## Char.fromInt

```ernest
Char.fromInt : (Int) -> Optional(Char)
```

The character with code point `n`, or `None` outside U+0000 to U+10FFFF
or for a surrogate, U+D800 to U+DFFF.

## Char.compare

```ernest

```

The order of the code points, which `<` and the other comparisons use.

### Examples

```ernest

// => Greater
```
