# Ernest module Char

*Since 0.1.0.*

Operations on `Char`, a Unicode scalar value (report §3.1). The predicates
use the code point's Unicode properties; the ordering is the prelude's
(report §9.6), by code point.

## Examples

```ernest
#(Char.isDigit('7'), Char.isAlpha('中'), Char.toUpper('é'))
// => #(true, true, 'É')
```

```ernest
#(Char.toInt('A'), Char.fromInt(66), Char.fromInt(0xD800))
// => #(65, Some('B'), None)
```

## See also

`String.toList`, `String.fromList`.

## Char.isDigit

```ernest
Char.isDigit(char : Char) : Bool
```

`true` for a decimal digit in any script, general category Nd.

## Char.isAsciiDigit

```ernest
Char.isAsciiDigit(char : Char) : Bool
```

`true` for one of the digits `0` to `9`, those `String.toInt` reads;
`isDigit` accepts a digit of any script.

### Examples

```ernest
#(Char.isAsciiDigit('7'), Char.isAsciiDigit('٣'), Char.isDigit('٣'))
// => #(true, false, true)
```

## Char.digitValue

```ernest
Char.digitValue(char : Char, base : Int) : Optional(Int)
```

*Since 0.3.0.*

The character's value as a digit in the base, 2 to 36: `0` to `9`, then
a letter in either case, `a` and `A` 10 to `z` and `Z` 35, the digits
`Int.toStringBase` writes and `String.toIntBase` reads. `None` for a
character that is no digit of the base, and for a base outside 2 to 36.

### Examples

```ernest
#(Char.digitValue('7', 10), Char.digitValue('F', 16), Char.digitValue('9', 8))
// => #(Some(7), Some(15), None)
```

## Char.isAlpha

```ernest
Char.isAlpha(char : Char) : Bool
```

`true` for a letter in any script, general category L.

## Char.isSpace

```ernest
Char.isSpace(char : Char) : Bool
```

`true` for white space, the White_Space property: `' '`, `'\n'`, and the
wider spaces of other scripts.

### Examples

```ernest
#(Char.isSpace('\n'), Char.isSpace('a'))
// => #(true, false)
```

Char.isUpper(char : Char) : Bool

## Char.toUpper

```ernest
Char.toUpper(char : Char) : Char
```

The upper-case form, or `char` itself when it has no single upper-case
form: `'ß'` stays `'ß'`.

## Char.toLower

```ernest
Char.toLower(char : Char) : Char
```

The lower-case form, or `char` itself when it has no single lower-case form.

### Examples

```ernest
Char.toLower('A')
// => 'a'
```

The one-character string.

## Char.toInt

The code point.

## Char.fromInt

```ernest
Char.fromInt(code : Int) : Optional(Char)
```

The character with code point `code`, or `None` outside U+0000 to U+10FFFF
or for a surrogate, U+D800 to U+DFFF.

## Char.compare

```ernest
Char.compare(left : Char, right : Char) : Ordering
```

The order of the code points, which `<` and the other comparisons use.

### Examples

```ernest
Char.compare('b', 'a')
// => Greater
```
