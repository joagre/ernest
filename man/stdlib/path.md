# Ernest module Path

*Since 0.1.0.*

Operations on `Path`, a file system path in the runtime's syntax
(report §9.3, Appendix E.14). A `Path` is `Path(String)`, so a path is
built from text and `toString` gives it back. There is no `fromString`:
the constructor is it, `Path("/etc/hosts")`. An absolute path's first
segment is its root, the text up to its first separator and that
separator.

## Examples

```ernest
Path.toString(Path("/etc") <> Path("hosts"))
// => "/etc/hosts"
```

```ernest
#(Path.name(Path("/tmp/report.txt")), Path.extension(Path("/tmp/report.txt")))
// => #(Some("report.txt"), Some("txt"))
```

## See also

`Fs` for reading and writing what a path names, `String` for the text.

## Path.<>

```ernest
Path.<>(path : Path, under : Path) : Path
```

*Since 0.2.0.*

The second path under the first: the segments of both, `split` then
`join`, so `Path("a//b") <> Path("c")` is `Path("a/b/c")`. An absolute
second is the result, as it was written (report Appendix E.14).

### Examples

```ernest
#(Path.toString(Path("/etc/") <> Path("hosts")), Path.toString(Path("/etc") <> Path("/var")))
// => #("/etc/hosts", "/var")
```

## Path.join

```ernest
Path.join(segments : List(String)) : Path
```

The segments as a path, the inverse of `split`: a root first stays a
root, and one separator stands between the others.

### Examples

```ernest
Path.toString(Path.join(Path.split(Path("/etc//hosts"))))
// => "/etc/hosts"
```

## Path.split

```ernest
Path.split(path : Path) : List(String)
```

The segments, none empty; an absolute path's first segment is the root.

### Examples

```ernest
Path.split(Path("/etc/hosts"))
// => ["/", "etc", "hosts"]
```

## Path.parent

```ernest
Path.parent(path : Path) : Optional(Path)
```

The path without its last segment, or `None` for a bare name and for the
root.

### Examples

```ernest
#(Path.parent(Path("/etc/hosts")), Path.parent(Path("hosts")))
// => #(Some(Path("/etc")), None)
```

```ernest
#(Path.parent(Path("a/b/")), Path.parent(Path("./x")), Path.parent(Path("/")))
// => #(Some(Path("a")), Some(Path(".")), None)
```

## Path.name

```ernest
Path.name(path : Path) : Optional(String)
```

The last segment, or `None` for the root, which has none, as it has no
`parent`.

### Examples

```ernest
#(Path.name(Path("a/b.txt")), Path.name(Path("/")))
// => #(Some("b.txt"), None)
```

## Path.extension

```ernest
Path.extension(path : Path) : Optional(String)
```

What follows the last `.` of the name, without the dot, or `None` when
the name has none. The dots that begin the name begin no extension, so
`.bashrc`, `.` and `..` have none.

## Path.withExtension

```ernest
Path.withExtension(path : Path, extension : String) : Path
```

The path with that extension in place of any it had, after a dot; an
empty one leaves the dot. The rest of the path stays as it was written.
The root, `.` and `..` have no name to extend, and are left as they
are.

### Examples

```ernest
#(Path.toString(Path.withExtension(Path("a/b.txt"), "md")),
  Path.toString(Path.withExtension(Path("a/b"), "")))
// => #("a/b.md", "a/b.")
```

## Path.withoutExtension

```ernest
Path.withoutExtension(path : Path) : Path
```

*Since 0.2.0.*

The path without its extension, the rest as it was written. The root,
`.` and `..` have no name to shorten, and are left as they are.

### Examples

```ernest
#(Path.toString(Path.withoutExtension(Path("a/b.txt"))),
  Path.toString(Path.withoutExtension(Path(".bashrc"))))
// => #("a/b", ".bashrc")
```

## Path.under

```ernest
Path.under(root : Path, path : Path) : Optional(Path)
```

*Since 0.3.0.*

The path placed under the root, where it is relative and each of its
segments names an entry: `None` for an absolute path, an empty one, or
one with a `.` or `..` segment, so that a name from outside the program
stays under the root, where `<>` would let it leave. It reads the text
alone: a link under the root may still lead out of it, which is the
file system's (Appendix E.17).

### Examples

```ernest
#(Optional.map(Path.under(Path("/srv"), Path("site/index.html")), Path.toString),
  Path.under(Path("/srv"), Path("../etc")),
  Path.under(Path("/srv"), Path("/etc")))
// => #(Some("/srv/site/index.html"), None, None)
```

## Path.isAbsolute

```ernest
Path.isAbsolute(path : Path) : Bool
```

`true` when the path starts at a root.

### Examples

```ernest
#(Path.isAbsolute(Path("/etc")), Path.isAbsolute(Path("etc")))
// => #(true, false)
```

## Path.toString

```ernest
Path.toString(path : Path) : String
```

The path as text, as it was written.
