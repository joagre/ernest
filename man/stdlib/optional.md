# Ernest module Optional

*Since 0.1.0.*

A value that may be absent. `Optional(a)` is `Some(a)` or `None`, a
prelude type (report §9.3); this module holds the operations over it. A
function that may find nothing returns an `Optional`, and `<-` in a block
unwraps one (report §5.5).

## Examples

```ernest
Optional.map(Some(2), fn(n) = n * 10)
// => Some(20)
```

```ernest
Optional.andThen(Some(4), fn(n) = if n > 0 then Some(n - 1) else None)
// => Some(3)
```

```ernest
Optional.withDefault(None, 0)
// => 0
```


not called on `None`.

## Optional.andThen


The function's result for `Some`, or `None` without calling it: one step
of a chain in which any step may find nothing.
