# Ernest module Foreign

*Since 0.1.0.*

Operations on `Term`, any value of the runtime, which a `foreign fn`
gives back where its result has no Ernest type (report §3.8, §8.4).
These functions ask what a term is, each answering `None` when it is
something else. `from` goes the other way, since an Ernest value is
already a value of the runtime.

## Examples

```ernest
#(Foreign.toInt(Foreign.from(42)), Foreign.toInt(Foreign.from("42")))
// => #(Some(42), None)
```

```ernest
let terms = Foreign.toList(Foreign.from([1, 2]));
Optional.map(terms, fn(list) = List.filterMap(list, Foreign.toInt))
// => Some([1, 2])
```

## Foreign.Term

```ernest
foreign type Term
```

*Since 0.2.0.*

Any value of the runtime, which the language does not inspect. It is a
foreign type, so its `==` is the runtime's exact equality (report
§3.10).

### Examples

```ernest
#(Foreign.from(1) == Foreign.from(1), Foreign.from(1) == Foreign.from(1.0))
// => #(true, false)
```

### Examples


## Foreign.toString

```ernest
Foreign.toString : (Term) -> Optional(String)
```

The `String` it is, or `None`; a binary that is not UTF-8 is `None`.

### Examples

```ernest
Foreign.toString(Foreign.from("hi"))
// => Some("hi")
```

## Foreign.toBytes

```ernest
Foreign.toBytes : (Term) -> Optional(Bytes)
```

*Since 0.2.0.*

The `Bytes` it is, or `None`: any binary, UTF-8 or not, a `String`
among them.

### Examples

```ernest
#(Foreign.toBytes(Foreign.from(<<255>>)), Foreign.toBytes(Foreign.from(1)))
// => #(Some(<<255>>), None)
```

## Foreign.toBool

```ernest
Foreign.toBool : (Term) -> Optional(Bool)
```

The `Bool` it is, or `None`.

### Examples

```ernest
#(Foreign.toBool(Foreign.from(true)), Foreign.toBool(Erl.atom("ready")))
// => #(Some(true), None)
```
