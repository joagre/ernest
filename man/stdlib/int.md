# Ernest module Int

*Since 0.1.0.*

Operations on `Int`, the integers of arbitrary precision (report §3.1).
The arithmetic and the ordering are the prelude's (report §9.6); this
module provides them with the rest.

## Examples

```ernest
Int.toString(Int.max(Int.abs(-7), 3))
// => "7"
```

```ernest
#(Int.div(-7, 3), Int.rem(-7, 3), Int.div(1, 0))
// => #(Some(-2), Some(-1), None)
```

## Int./

```ernest
Int./ : (Int, Int) -> Int
```

The quotient, truncated toward zero: `-7 / 3` is `-2`.

### Errors

Faults with `Fault("division by zero")` when `b` is `0`; `Int.div` does not.

## Int.%

```ernest
Int.% : (Int, Int) -> Int
```

The remainder of `/`, with the sign of `a`: `-7 % 3` is `-1`.

### Errors

Faults with `Fault("division by zero")` when `b` is `0`; `Int.rem` does not.

## Int.shiftLeft

```ernest
Int.shiftLeft : (Int, Int) -> Int
```

`n` shifted left by `count` bits: `n` times two to the power `count`; a
count below 0 is none (report §7.4).

### Examples

```ernest
#(Int.shiftLeft(3, 2), Int.shiftRight(-7, 2), Int.shiftLeft(3, -1))
// => #(12, -2, 3)
```

## Int.shiftRight

```ernest
Int.shiftRight : (Int, Int) -> Int
```

`n` shifted right by `count` bits, the sign kept: `n` divided by two to
the power `count`, rounded toward negative infinity; a count below 0 is
none.

## Int.pow

```ernest
Int.pow : (Int, Int) -> Optional(Int)
```

`base` raised to `exponent`, exactly, or `None` when the exponent is
negative, since that is not an `Int`.

### Examples

```ernest
#(Int.pow(2, 10), Int.pow(2, -1))
// => #(Some(1024), None)
```

## Int.toStringBase

```ernest
Int.toStringBase : (Int, Int) -> Optional(String)
```

The digits of `n` in that base, 2 to 36, letters upper case, with a
leading `-` when negative; `None` outside those bases.

### Examples

```ernest
#(Int.toStringBase(255, 16), Int.toStringBase(5, 1))
// => #(Some("FF"), None)
```

## Int.toFloat

```ernest
Int.toFloat : (Int) -> Float
```

The nearest `Float`, ties to even.

### Errors

Faults with `Fault("Int out of Float range")` beyond the largest finite
`Float` (report §3.1).

### Examples

```ernest
Int.toFloat(7)
// => 7.0
```
