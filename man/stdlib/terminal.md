# Ernest module Terminal

*Since 0.1.0.*

The terminal through its system process, which reads it
(report §8.2). A subscriber is sent every key pressed from then on,
the text of a paste as one `Pasted`, and the new size whenever the
window changes, wrapped for its own mailbox, as `monitor` and
`Clock.alarm` deliver. Where standard input is not a terminal there are
no keys, and a subscription is refused. The terminal read as keys and
the terminal read as lines are the same one, so a program subscribes
here or reads lines with `Io.readLine`, never both.

## Examples

```ernest
match Terminal.subscribe(fn(event) = event) {
    Right(_) -> "keys"
  | Left(Io.NotATerminal) -> "lines"
  | Left(_) -> "neither"
}
```

## See also

`Io.readLine` for the same terminal read as lines, `Clock.alarm` for the
other message that arrives later.

## Terminal.Size

```ernest
type Size = Size(rows : Int, columns : Int)
```

The terminal's window, in rows and columns, as the terminal reports it
(report §8.2).

### Examples

```ernest
Terminal.Size(rows = 24, columns = 80)
// => Size(rows = 24, columns = 80)
```

## Terminal.Event

```ernest
type Event =
    Key(Char)
  | ArrowUp
  | ArrowDown
  | ArrowLeft
  | ArrowRight
  | Escape
  | Interrupt
  | Pasted(String)
  | Resized(Size)
```

What the terminal delivers to its subscriber: a key, `Enter` and
Backspace among them as their characters, an arrow, `Escape`, the
interrupt, a paste, or a new size (report §8.2).

### Examples

```ernest
match Terminal.Key('q') {
    Terminal.Key(c) -> c == 'q'
  | _ -> false
}
// => true
```

## Terminal.subscribe

```ernest
Terminal.subscribe : ((Event) -> m) -> Either(Io.Error, Unit) with m
```

Every key pressed and every resize from now on, wrapped, in the
caller's mailbox. It answers once the terminal is in the mode the keys
need, so that nothing typed after it returns is echoed (report §8.2),
or with `Left(Io.NotATerminal)` where standard input is not a terminal,
claiming nothing, so that the program can read lines instead. A process
holds one subscription: a second call replaces the first, and the keys
come wrapped the new way from then on. A subscription ends when its
process dies or restarts (report §6.9). The terminal applies each
subscriber's wrap itself, in order, so a wrap that does not finish
delays that subscriber's keys and no other's.

## Terminal.size

```ernest
Terminal.size : () -> Either(Io.Error, Size) with m+
```

The terminal's size now, or `Left(Io.NotATerminal)` where standard
output is not a terminal. A program that draws asks at each redraw and
hears of a change as `Resized`.

### Examples

```ernest
match Terminal.size() {
    Left(_) -> 24
  | Right(Terminal.Size(rows = rows)) -> rows
}
```

## Terminal.columns

```ernest
Terminal.columns : (String) -> Int
```

The columns the text takes at a terminal, counted by grapheme: two for
one East Asian Wide or Fullwidth or of emoji presentation, or an
extended pictographic one followed by U+FE0F, none for one only of
combining marks, format characters and controls, a tab among them,
whose width is the caller's, and one for any other. An escape sequence
takes none, so styled text counts as its text does.

### Examples

```ernest
#(Terminal.columns("a中"), Terminal.columns("\u{1b}[1mab\u{1b}[22m"))
// => #(3, 2)
```
