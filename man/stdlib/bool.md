# Ernest module Bool

*Since 0.1.0.*

Operations on `Bool`, the type of `true` and `false`. The language
itself has `&&`, `||`, `!`, and `if`; this module holds the rest.

## Examples

```ernest
Bool.not(1 < 2)
// => false
```

```ernest
Bool.toString(true)
// => "true"
```

## Bool.not

```ernest
Bool.not(bool : Bool) : Bool
```

The other truth value, which prefix `!` also gives (report §4.8).

## Bool.toString

```ernest
Bool.toString(bool : Bool) : String
```

`"true"` or `"false"`.
