# Ernest module Either

*Since 0.1.0.*

A value or the cause of its absence. `Either(e, a)` is `Left(e)`, the
cause, or `Right(a)`, the value, a prelude type (report §9.3); this module
holds the operations over it. A function that can fail with a cause
returns an `Either` (Appendix E.0 shape rule 4), and `<-` in a block unwraps one
(report §5.5).

## Examples

```ernest
let found : Either(String, Int) = Right(2);
Either.map(found, fn(n) = n * 10)
// => Right(20)
```

```ernest
Either.andThen(Right(3), fn(n) = if n > 5 then Right(n) else Left("small"))
// => Left("small")
```

```ernest
Either.withDefault(Left("gone"), 0)
// => 0
```

## Either.withDefault


The value in `Right`, or the default for `Left`.

## Either.map

```ernest
Either.map : (Either(e, a), (a) -> b with x) -> Either(e, b) with x
```

`Right` of the function applied to the value, or the `Left` unchanged;
the function is not called on `Left`.

## Either.mapLeft

```ernest
Either.mapLeft : (Either(e, a), (e) -> b with x) -> Either(b, a) with x
```

`Left` of the function applied to the cause, or the `Right` unchanged.

### Examples

```ernest
let failed : Either(String, Int) = Left("bad");
Either.mapLeft(failed, fn(s) = s <> "!")
// => Left("bad!")
```

## Either.andThen

```ernest
Either.andThen : (Either(e, a), (a) -> Either(e, b) with x) -> Either(e, b) with x
```

The function's result for `Right`, or the `Left` unchanged without
calling it: one step of a chain in which any step may fail.

## Either.toOptional

```ernest
Either.toOptional : (Either(e!, a)) -> Optional(a)
```

`Some` of the value in `Right`, or `None`; the cause is dropped.

### Examples

```ernest
Either.toOptional(Right(3))
// => Some(3)
```

## Either.fromOptional

```ernest
Either.fromOptional : (Optional(a), e!) -> Either(e!, a)
```

`Right` of the value in `Some`, or `Left` of the given cause for `None`.

### Examples

```ernest
let nothing : Optional(Int) = None;
Either.fromOptional(nothing, "missing")
// => Left("missing")
```
