# Ernest module Either

*Since 0.1.0.*

Operations on a value or the cause of its absence, `Either(e, a)`:
`Right(a)`, the value, or `Left(e)`, the cause.

A function that can fail for a cause the caller can act on answers an
`Either`: `Fs.read` answers `Left(Io.NotFound)` for a file that is not
there. Where there is no cause to tell, an `Optional` serves.

A `match` takes an `Either` apart. In a block, `let x <- e` unwraps a
`Right` and goes on, and ends the block with the `Left` where `e` is one
(report §5.5).

## Examples

`map` changes the value of a `Right`:

```ernest
{
    let found : Either(String, Int) = Right(2);
    Either.map(found, fn(n) = n * 10)
}
// => Right(20)
```

`andThen` chains a step that can fail, and here it fails:

```ernest
Either.andThen(Right(3), fn(n) = if n > 5 then Right(n) else Left("small"))
// => Left("small")
```

`withDefault` answers the default for a `Left`:

```ernest
Either.withDefault(Left("gone"), 0)
// => 0
```

`Optional`, when the absence needs no cause.

## Either.isLeft

```ernest
Either.isLeft(either : Either(e!, a!)) : Bool
```

`true` for a `Left`.

### Examples

```ernest
Either.isLeft(Left(1))
// => true
```

## Either.isRight

```ernest
Either.isRight(either : Either(e!, a!)) : Bool
```

`true` for a `Right`.

### Examples

```ernest
Either.isRight(Left(1))
// => false
```

## Either.withDefault

```ernest
Either.withDefault(either : Either(e!, a!), default : a!) : a!
```

The value in a `Right`, or `default` for a `Left`, whose cause is dropped.

## Either.map

```ernest
Either.map(either : Either(e, a), f : (a) -> b with x) : Either(e, b) with x
```

`Right(f(x))` for `Right(x)`, or the `Left` as it is, where `f` is not
called.

## Either.mapLeft

```ernest
Either.mapLeft(either : Either(e, a), f : (e) -> b with x) : Either(b, a) with x
```

`Left(f(cause))` for `Left(cause)`, or the `Right` as it is, where `f` is
not called. It turns one module's error into another's.

### Examples

```ernest
{
    let failed : Either(String, Int) = Left("bad");
    Either.mapLeft(failed, fn(s) = s <> "!")
}
// => Left("bad!")
```

## Either.andThen

```ernest
Either.andThen(either : Either(e, a), f : (a) -> Either(e, b) with x) : Either(e, b) with x
```

`f(x)` for `Right(x)`, or the `Left` as it is, where `f` is not called. It
chains steps each of which may fail, as `<-` does in a block.

## Either.toOptional

```ernest
Either.toOptional(either : Either(e!, a)) : Optional(a)
```

`Some(x)` for `Right(x)`, or `None` for a `Left`, whose cause is dropped.

### Examples

```ernest
Either.toOptional(Right(3))
// => Some(3)
```

## Either.fromOptional

```ernest
Either.fromOptional(optional : Optional(a), cause : e!) : Either(e!, a)
```

`Right(x)` for `Some(x)`, or `Left(cause)` for `None`: the cause an
`Optional` did not carry.

### Examples

```ernest
{
    let nothing : Optional(Int) = None;
    Either.fromOptional(nothing, "missing")
}
// => Left("missing")
```
