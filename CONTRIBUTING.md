# Contributing

Ernest takes no contributions before 1.0: no pull requests and no patches. Until then the language is being settled, and its report, its toolchain and its library change together from one day to the next.

What helps is a defect found. Open an issue at https://github.com/joagre/ernest/issues with the program or the commands that show it, what Ernest did, and what you expected; where the report states the rule it breaks, name the section. The issues are for defects alone.

This changes at 1.0.
