# Contributing

Ernest takes no contributions before 1.0: no pull requests and no patches.

What helps is a defect found. Open an issue at https://github.com/joagre/ernest/issues with the program or the commands that show it, what Ernest did, and what you expected; where the report states the rule it breaks, name the section.

So does a place where writing Ernest felt against one of the report's five principles (§0): a workaround, a second way, something invisible, a function the library lacks. Open an issue with the finding, the program that shows it, the principle and what you ask.

The issues are for these two alone, each by its form.

A security hole goes as [`SECURITY.md`](SECURITY.md) says, and not to the issues.
