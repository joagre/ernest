# The guides

What a user of Ernest reads, five documents, each for the reader its row names. Each rule any of them states is the report's, [`report/`](../report/), which they cite by section; the tour, [`tour/`](../tour/), is the third way in, one program grown through eight chapters.

| File | For whom | What it is | How long |
|---|---|---|---|
| [`language.md`](language.md) | the programmer learning Ernest, who has used a functional language | *Programming in Ernest*, the guide: what the compiler refuses, then a program run, values, functions, protocols, processes, failure, modules, nodes and foreign code, the tools, Ernest from Erlang, the design, and exercises with their answers, each rule taught where a program first needs it, with the report's section named | an afternoon to read; the exercises take longer |
| [`why.md`](why.md) | the programmer who wants the argument before the rules | *Why Ernest*: six claims, four of them with a program, one with its configuration file and one with the report, for what the language adds where its parts meet | twenty minutes |
| [`faq.md`](faq.md) | the reader who brings a question, from Gleam, from Erlang or from Unison | the questions a reader of the guide brings, each answered by what Ernest does, with the section that states it | a quarter of an hour, or one answer |
| [`deployment.md`](deployment.md) | the operator, who runs programs as nodes and reads what they write | one node, two nodes, services, code across nodes, builds, looking in, what a node says and what to do, and a deployment end to end; it assumes nothing of the language beyond what a program's author says | an hour, with the commands typed along |
| [`style.md`](style.md) | the programmer about to write a module | what a program written in Ernest looks like: what `ern format` writes, what the report asks of a library's names, what the standard library does with names, and the names every program shares; installed with the guide | ten minutes, then kept open |

Where to begin: `why.md` if you doubt, the tour if you want the picture in an evening, `language.md` if you want the language, `deployment.md` if you run it. The guide's §0 shows what the compiler refuses and how it says so, and its §1 runs the first program.
