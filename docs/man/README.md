# The manual pages

A page holds a module's doc block, then its declarations, each with its type and its own doc block (report §11.4). Where Ernest is installed, `man Ernest.List` shows a module's page and `man ern` the toolchain's.

- [The prelude and the standard library](stdlib/README.md)
- [The libraries under `src/libs/`](libs/README.md)
- [`ern`, the toolchain and its shell](../../report/toolchain.md#11-toolchain), the report's §11, whose §11.2 gives the shell's commands

The pages `ern doc` writes for Ernest 0.10.0.
