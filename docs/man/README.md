# The manual pages

The pages `ern doc` wrote from `main` when `make man` last ran, the last release then being Ernest 0.4.0; a module or a declaration that appeared after it ends its doc block with the release that brings it. A page holds a module's doc block, then its declarations, each with its type and its own doc block (report §11.4). Where Ernest is installed, `man Ernest.List` shows a module's page and `man ern` the toolchain's.
