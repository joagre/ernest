# Ernest module Crypto

*Since 0.9.0.*

The SHA-1 digest of bytes, and bytes from the host's strong random source.

Use `sha1` where a protocol names SHA-1, as WebSocket's opening handshake
does (RFC 6455). Two inputs with one SHA-1 digest have been found, so a
digest that a forger must not match is not SHA-1's to give. Use
`randomBytes` for what must not be guessed, a key, a token or a cookie;
numbers a program draws for a simulation or a test, which a seed
repeats, are `Random`'s.

The library stands on every job's load path, so a program names it with
no option (report Appendix G).

**The strong random source.** `randomBytes` draws from the host's
generator for keys, which the operating system's entropy seeds and mixes
again as it runs. Where the generator fails for lack of entropy, the call
faults, and no bytes are drawn from a weaker source.

## Examples

The digest of `abc`, FIPS 180-4's example, in hexadecimal:

```ernest
Bytes.toHex(Crypto.sha1(String.toUtf8("abc")))
// => "A9993E364706816ABA3E25717850C26C9CD0D89D"
```

A token of 16 random bytes, in hexadecimal, another at every call:

```ernest
Bytes.toHex(Crypto.randomBytes(16))
```

## See also

`Random` for numbers drawn from a seed, `Bytes.toHex` to write bytes as
text.

## Crypto.sha1

```ernest
Crypto.sha1(bytes : Bytes) : Bytes
```

The SHA-1 digest of the bytes, 20 bytes, as FIPS 180-4 defines it. Empty
bytes have one too.

### Examples

```ernest
Bytes.toHex(Crypto.sha1(<<>>))
// => "DA39A3EE5E6B4B0D3255BFEF95601890AFD80709"
```

## Crypto.randomBytes

```ernest
Crypto.randomBytes(count : Int) : Bytes
```

`count` bytes from the host's strong random source, each of the 256
values as likely as any other. A count below 0 is 0, which answers no
bytes (report §7.4).

### Errors

Faults where the host's generator fails for lack of entropy, a limit of
the host the program did not cause (report §7.4), with the cause `foreign
function crypto:strong_rand_bytes/1 raised error:low_entropy`.

### Examples

```ernest
#(Bytes.size(Crypto.randomBytes(16)), Crypto.randomBytes(-1))
// => #(16, <<>>)
```
