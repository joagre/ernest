# Ernest module Base64

*Since 0.9.0.*

Bytes written as text in the base 64 encoding of RFC 4648, and the text
read back as the bytes.

Use it where a protocol or a format carries bytes as text, as an HTTP
header's credentials or a WebSocket handshake's key are carried. For
bytes a person reads, `Bytes.toHex` writes two hexadecimal digits a
byte.

The library stands on every job's load path, so a program names it with
no option (report Appendix G).

**The alphabet.** `encode` writes the standard alphabet, `A` to `Z`, `a`
to `z`, `0` to `9`, `+` and `/`, each character six bits of the bytes,
and pads the text with `=` to a multiple of four characters. The
alphabet of URLs and file names, with `-` and `_` for `+` and `/`, is
neither written nor read, and neither is a text without its padding.

**Reading.** `decode` reads the texts `encode` writes and no other. It
answers `None` for a character outside the alphabet, white space and
line breaks among them; for a count of characters that is no multiple of
four; for a `=` anywhere but as the last one or two characters; and for
a last character before a `=` that sets a bit the bytes do not use, as
`Zh==` does, where `encode` writes `Zg==`. `decode(encode(bytes))` is
`Some(bytes)`.

## Examples

Text written in base 64:

```ernest
Base64.encode(String.toUtf8("Ernest"))
// => "RXJuZXN0"
```

The text read back:

```ernest
Optional.andThen(Base64.decode("RXJuZXN0"), String.fromUtf8)
// => Some("Ernest")
```

## Base64.encode

```ernest
Base64.encode(bytes : Bytes) : String
```

`bytes` in base 64, four characters for each three bytes, and for the
one or two bytes left at the end four characters that end in two `=` or
one.

The empty bytes are the empty text.

### Examples

```ernest
#(Base64.encode(<<102>>), Base64.encode(<<102, 111>>), Base64.encode(<<251, 255, 191>>))
// => #("Zg==", "Zm8=", "+/+/")
```

## Base64.decode

```ernest
Base64.decode(text : String) : Optional(Bytes)
```

The bytes that `text` writes in base 64, or `None` where `text` is not
what `encode` writes of any bytes.

The empty text is the empty bytes.

### Examples

```ernest
#(Base64.decode("Zm8="), Base64.decode("Zm8"), Base64.decode("Zm-v"))
// => #(Some(<<102, 111>>), None, None)
```
