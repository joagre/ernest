# Ernest module Json

*Since 0.4.0.*

JSON text, read into a value and written from one, as RFC 8259 defines
it, by the host's `json` module.

The library stands on every job's load path, so a program names it with
no option (report Appendix G).

**Numbers.** A number written with neither a fraction nor an exponent is
an `Integer`, of any size the host can hold, and one written with either
is a `Real`: `1` is `Integer(1)`, and `1.0` and `1e0` are `Real(1.0)`. A
`Real` nearer to zero than a `Float` can hold is `0.0`, and so is `-0.0`,
since a `Float` has no negative zero (report §3.1). An integer longer than
the host can hold, and a real larger than a `Float` can hold, are not
read.

**Objects.** An object is a `Map` from its members' names to their
values. Where a text names a member twice, the last is kept, as
`Map.fromList` keeps a later pair. `format` writes the members in the
order of their names' code points, an order of this library's, which the
host's `json:format` leaves to its caller.

**Reading back.** `parse` reads what `format` writes as the value it was
written from.

## Examples

A member of an object read:

```ernest
match Json.parse("{\"name\": \"desk\", \"port\": 4001}") {
    Right(Json.Object(members)) -> Map.get(members, "port")
  | _ -> None
}
// => Some(Integer(4001))
```

An object written:

```ernest
Json.format(Json.Object(Map.fromList([#("port", Json.Integer(4001)),
                                      #("name", Json.Text("desk"))])))
// => "{\n  \"name\": \"desk\",\n  \"port\": 4001\n}\n"
```

## Json.Value

```ernest
type Value =
    Null
  | Boolean(Bool)
  | Integer(Int)
  | Real(Float)
  | Text(String)
  | Array(List(Value))
  | Object(Map(String, Value))
```

A JSON value: `null`, `true` or `false`, a number, a string, an array or
an object.

### Examples

```ernest
Json.parse("[null, true, 2, 2.5, \"x\", []]")
// => Right(Array([Null, Boolean(true), Integer(2), Real(2.5), Text("x"), Array([])]))
```

## Json.Error

```ernest
type Error = UnexpectedEnd | UnexpectedByte(Int) | UnexpectedSequence(Bytes)
```

Why a text holds no JSON value, as the host's `json` finds it, which
does not say where. `UnexpectedEnd` is a text that ends inside its value
or holds none. `UnexpectedByte` is a byte that cannot stand where it is,
the first of its character's: a second value, a comma before a closing
bracket, or a character no value begins with. `UnexpectedSequence` is an
escape that writes no character, a surrogate's escape without its pair's
among them, or a number the host cannot hold, an integer too long or a
real larger than a `Float` can hold, in the host's spelling of it.

### Examples

```ernest
#(Json.parse("[1, 2"), Json.parse("[1, 2,]"))
// => #(Left(UnexpectedEnd), Left(UnexpectedByte(93)))
```

## Json.parse

```ernest
Json.parse(text : String) : Either(Error, Value)
```

The value `text` writes, or why it writes none. White space may stand
before the value and after it, and nothing else may.

### Examples

```ernest
#(Json.parse(" 4001 "), Json.parse("4001 4002"))
// => #(Right(Integer(4001)), Left(UnexpectedByte(32)))
```

## Json.format

```ernest
Json.format(value : Value) : String
```

`value` as JSON text, laid out over lines as the host's `json:format`
lays it out, two spaces to a level, an object's members in the order of
their names' code points, and ending in a line feed.

### Examples

```ernest
Json.format(Json.Array([Json.Integer(1), Json.Null]))
// => "[1,null]\n"
```
