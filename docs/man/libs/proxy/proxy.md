# Ernest module Proxy

*Since 0.4.0.*

A proxy for a service a peer offers: one address for the service across
its end and its return.

The library stands on every job's load path, so a program names it with
no option (report Appendix G).

**What it does.** `start` spawns the proxy's process, which finds the
service and forwards to it each message it is sent, and answers the
proxy's address, which the program sends to. When the find fails, the
service ends or its node is lost, the process finds the service again
when the next message comes; a message that comes while a find is under
way waits for it and shares its outcome, so that one find is under way at
a time. A message that comes
while the service is away, and whose find fails, goes to the last address
held, where it is lost as a message to an ended process is, or reaches the
service where its node is back; a call through the proxy's address then
answers `None` at its own time, which says nothing of whether the request
ran. A service the configuration does not list is never found. A find that
answers `OtherType` is no absence but a protocol the two builds disagree
on: the process faults, naming the service, and the address is dead from
then on. At a shell prompt the caller is the input's process, which ends
with the input, so a proxy used from the prompt is started in a process
that lives on. `start` spawns two processes, the forwarder and one that
ends at once and stands where no address has been found. The process ends
with the process that called `start`.

**What it is not.** It is an ordinary process on the message's way: a
message through it may pass one sent to the service directly, and it
keeps nothing of a message it could not deliver. A program that is to
monitor the service itself holds the address `Peer.find` gives (report
§8.7).

## Examples

A client of the counter, whose calls go to the counter wherever it is
back:

```ernest
{
    let service : Peer.Service(Int) = Peer.service("counter");
    Proxy.start(service, 5000)
}
```

## Proxy.start

```ernest
Proxy.start(service : Peer.Service(m), ms : Int) : Address(m)
```

Spawns the process of a proxy for `service`, and answers the proxy's
address. The process finds the service within `ms` milliseconds, and again
within `ms` at the first message after the find failed, the service ended
or its node was lost, a message that comes during a find sharing its
outcome, and forwards each message to the service. A message that comes
while the service is away and whose find fails goes to the last address
held, lost where that process has ended (report §6.2); a call through the
address then answers `None` at its own time. A find that answers
`OtherType` faults the process with a cause that names the service by its
name, `the service counter is offered at another type`. The process ends
with the process that called `start`.

### Examples

```ernest
{
    let service : Peer.Service(Int) = Peer.service("counter");
    send(Proxy.start(service, 5000), 1)
}
```
