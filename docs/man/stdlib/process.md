# Ernest module Process

*Since 0.1.0.*

Processes as values: telling them apart, and seeing what the runtime runs.

A `Process` is the identity of a process. It has equality, so it keys a
`Map` and is an element of a `Set`, and it has no order. Nothing can be sent
to it: an address is what a process is reached by, and a `Process` only says
which one. `current` gives the running process, `fromAddress` the process
behind an address, and `monitor` watches one.

`status`, `live` and `faults` show what runs, for a program that watches
itself. What they say of a live process is a snapshot, which may have
changed by the time it is read, and the runtime keeps nothing of a process
that has ended (report Appendix E.21).

## Examples

The caller is among the processes the runtime runs:

```ernest
List.contains(Process.live(), Process.current())
// => true
```

## See also

`monitor` for learning how a process one holds ended, `Io.debug`, which
prints a process by the number the runtime gives it.

## Process.Status

```ernest
type Status = Status(site : String, queued : Int, activity : Activity)
```

*Since 0.4.0.*

What the runtime knows of a live process: where it was spawned, as `Down`'s
site names it, how many messages wait in its mailbox, and what it is doing.

### Examples

```ernest
Optional.map(Process.status(Process.current()), fn(status) = status.activity)
// => Some(Running)
```

## Process.Activity

```ernest
type Activity = Running | Receiving | Calling
```

What a live process is doing: running, waiting in a `receive`, or waiting
for the answer to a call.

### Examples

```ernest
Process.Receiving
// => Receiving
```

## Process.FaultReport

```ernest
type FaultReport =
    FaultReport(process : Process,
                site : String,
                cause : String,
                restarted : Bool,
                trace : String,
                spawnedBy : Optional(String))
```

A fault of a process the runtime started: the process, where it was spawned,
the cause, whether it restarts after the fault, its trace, and the name of
the peer whose spawn started the process, as the configuration lists it
(report §8.7), or `None`. The trace is the innermost twelve frames of the
host's stack where the fault was met, the innermost first, a frame a line,
a frame of Ernest code written as a spawn site is, `Main.worker:3`
(report §7.3, Appendix E.21).

### Examples

```ernest
Process.FaultReport(process = Process.current(),
                    site = "Main.worker:3",
                    cause = "division by zero",
                    restarted = false,
                    trace = "",
                    spawnedBy = None).cause
// => "division by zero"
```

## Process.fromAddress

```ernest
Process.fromAddress(address : Address(m)) : Process
```

The process behind the address, through every adapted address. Two addresses of one
process give equal processes, though addresses have no equality.

### Examples

```ernest
Process.fromAddress(self()) == Process.fromAddress(adapted(self(), fn(x) = x))
// => true
```

## Process.current

```ernest
Process.current() : Process
```

*Since 0.4.0.*

The running process, for a function that needs its identity and not its
mailbox; `self` gives its address. It is the process `fromAddress(self())`
gives. In a wrap the runtime applies, a monitor's, an alarm's or a
subscription's, it is the process the wrap delivers to (report §6.9).

### Examples

```ernest
Process.current() == Process.fromAddress(self())
// => true
```

## Process.status

```ernest
Process.status(process : Process) : Optional(Status)
```

*Since 0.4.0.*

A snapshot of the process, or `None` once it has ended, and for a process on
another node.

### Examples

```ernest
Optional.isSome(Process.status(Process.current()))
// => true
```

## Process.live

```ernest
Process.live() : List(Process)
```

The processes the runtime started that have not ended, in unspecified order:
those the program spawned, and each listener, socket or running program a
system module opened. The runtime's system processes are left out.

### Examples

```ernest
List.isEmpty(Process.live())
// => false
```

## Process.faults

```ernest
Process.faults(wrap : (FaultReport) -> m) : Unit receiving m
```

Puts `wrap(report)` in the caller's mailbox for every fault of every process
the runtime started, from now on, the system processes' left out. A process
holds one subscription: a second call replaces the first, and its `wrap` is
used from then on. A subscription ends when its process dies or restarts
(report §6.9), and keeps no deadlock from being found (report §8.6).

### Examples

```ernest
Process.faults(fn(report) = report)
```
