# Ernest module Optional

*Since 0.1.0.*

Operations on a value that may be absent, `Optional(a)`: `Some(a)` or
`None`.

A function that may find nothing answers an `Optional`: `List.get` past the
end of a list, or `Map.get` for a key the map does not hold. Where the
absence has a cause the caller should know, an `Either` says it instead.

A `match` takes an `Optional` apart. In a block, `let x <- e` unwraps a
`Some` and goes on, and ends the block with `None` where `e` is `None`
(report §5.5).

## Examples

`map` changes the value of a `Some`:

```ernest
Optional.map(Some(2), fn(n) = n * 10)
// => Some(20)
```

`andThen` chains a step that may find nothing:

```ernest
Optional.andThen(Some(4), fn(n) = if n > 0 then Some(n - 1) else None)
// => Some(3)
```

`withDefault` answers the default where there is no value:

```ernest
Optional.withDefault(None, 0)
// => 0
```

### Examples

```ernest

// => false
```

## Optional.withDefault


## Optional.map

```ernest
Optional.map(optional : Optional(a), f : (a) -> b with e) : Optional(b) with e
```

`Some(f(x))` for `Some(x)`, or `None` for `None`, where `f` is not called.

## Optional.andThen

```ernest
Optional.andThen(optional : Optional(a), f : (a) -> Optional(b) with e) : Optional(b) with e
```

`f(x)` for `Some(x)`, or `None` for `None`, where `f` is not called. It
chains steps each of which may find nothing, as `<-` does in a block.
