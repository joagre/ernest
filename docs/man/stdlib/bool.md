# Ernest module Bool

*Since 0.1.0.*

Operations on `Bool`, the type of `true` and `false`.

The language itself has `&&`, `||`, `!` and `if`. This module holds the
rest, `toString`.

## Examples

A `Bool` as text:

```ernest
Bool.toString(true)
// => "true"
```

## Bool.toString

```ernest
Bool.toString(bool : Bool) : String
```

`"true"` or `"false"`, which `String.toBool` reads back.
