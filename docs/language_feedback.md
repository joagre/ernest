# Language feedback

What writing Ernest has felt against the principles, and what a reader found that questions a rule of the language rather than showing a defect (CLAUDE.md, *Defects and gaps*). An entry stays until a plan item decides it: a report change, a "Later" entry in the log, a question in the plan, or a line saying it was weighed and left alone. 135. **Two modules of one library cannot share a private function** (2026-10-20, `ernest-epx`, `Epx.Gc` beside `Epx`). A declaration is private to its module or exported to every program (§4.2), so `Epx.Gc`, which checks a width and a color by the same rules and causes as `Epx`, writes the four checks again rather than export from `Epx` functions no caller should see; and since `Epx` cannot name a module that names it (§4.1), the tests of `Epx`'s drawing functions live in `Epx.Gc`, the one module that can make a context. Principle 2.

136. **A library has no name for a type its module is named after** (2026-10-21, `ernest-epx`, the window). Shape rule 7 refuses `Epx.Window.Window`, a type named for its module, and §4.2 refuses a type `Window` in `epx.ern` beside a module `epx/window.ern`, their namespaces coinciding; the prelude's way out, `Path` and `Process` as types beside the modules of their operations (§9), a library has not. The library named its module `Epx.Screen` so that the type is `Epx.Screen.Window`, where a reader predicts `Epx.Window.open` answering an `Epx.Window`. Principle 1.

137. **A message foreign code sends a process by its host identity is taken by a variable pattern as a message of the mailbox's type** (2026-10-21, the same, the window's close button). epx sends the process that opened a window `{epx_event, Window, close}` when its close button is pressed, whatever the window's flags; a `receive` whose patterns each name a constructor leaves it in the mailbox, and one whose pattern is a variable takes it as a `Down` whose `reason` prints `close`. §8.4 says a bad message on delivery faults the receiver, so this is a defect against the report, not a rule to weigh: a well-typed program read a value of another type. Principle 1, and the soundness argument.
