What writing Ernest has felt against the principles, and what a reader found that questions a rule of the language rather than showing a defect (CLAUDE.md, *Defects and gaps*). 146. **A request with named fields is made in a lambda at `Address.call`** (2026-10-23, the tour's spike, chapter 5). `Address.call(counter, Get, 1000)` takes the constructor as the function of the reply while `Get` has one positional field; once a field is named, `Get(key : String, reply : Reply(Int))`, the call is `Address.call(counter, fn(reply) = Get(key = key, reply = reply), 1000)`, and the compiler says so. The first form is the one the guide's chapter 4 teaches, and it stops working at the first request that carries anything beside its reply, which most do. Evidence on how a request is written, not a new claim. Principle 1.

147. **An inferred type variable prints under a letter the style refuses** (2026-10-23, the tour's spike, `Tally`). `:browse Tally` shows `Tally.inc : (Tally.Tally(a=), a=, Int) -> Tally.Tally(a=)` for a function whose variable is a map's key, which `guide/style.md` names `k`, while the annotated `empty` and `report` print `k=`; an exported function written without an annotation prints against the style the module's annotated functions follow. Whether the printer should take the declared type's letter where the variable is the type's own, or the style should ask every export to be annotated, is open. Principle 3.
