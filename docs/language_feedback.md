# Language feedback

What writing Ernest has felt against the principles, and what a reader found that questions a rule of the language rather than showing a defect (CLAUDE.md, *Defects and gaps*). An entry stays until a plan item decides it: a report change, an item of a milestone, or a line in the log saying it was dropped and why. An entry keeps its number, which the plan, the log and the code cite; the next is 259.

253. **Base 16 answers an `Optional` that is never `None`.** `Int.toStringBase(n, 16)` is written at three sites, the shell's `escapedChar` and `hexByte` and `Http`'s chunk size. The first two write a default for the `None` and the third a fault, and base 16 gives none. Found 2026-11-15 by item 49's read-back (the log's *A Refusal Holds No Control Character*); the plan's MVP 4.17, item 54.
254. **A started program's output has no line form.** E.0 rule 2 pairs `readLine` with `read` for a stream of text, and `Os.read` and `Tcp.read` answer pieces alone. Three programs hold the bytes read until a line feed: `tools/flakes.ern`'s `relay`, `examples/shout.ern`'s `serve`, and `Http`'s `line`, which holds its protocol's limit and carriage return too. Found 2026-11-15 by item 11's build, where the cut stays the program's (the log's *The Flake Hunt*); the plan's MVP 4.16, item 60.
255. **A read that lasts a program's whole life is given a time that bounds nothing.** Shape rule 8 gives `Os.read` its milliseconds, since a child can hang unseen (the log's *What Waits With a Limit*). `tools/flakes.ern`'s `relay` reads a host for as long as it runs: it reads again at each `Left(Timeout)`, and its time says only how often. The tools' `fileMs`, 10000 for a file, is a number chosen the same way in three programs. Found 2026-11-15 by item 11's build (the log's *The Flake Hunt*); the plan's MVP 4.16, item 60.
256. **A program is told nothing at the host's interrupt.** §8.6 ends it at once, the host taking no handler for that signal (the log's *The Build's First Group*). A program that made a directory cannot remove it then: `tools/flakes.ern` leaves its rounds' directory, which a termination removes. Found 2026-11-15 by item 11's build (the log's *The Flake Hunt*); the plan's MVP 4.16, item 60.
257. **An `Io.Error`'s message with its path is written at each site.** `"cannot read " <> Path.toString(path) <> ": " <> Io.show(error)`, the verb varying, stands at 13 sites in five programs: `tools/flakes.ern` 5, `tools/site/run.ern` 4, `tools/manual.ern` 2, `tools/site.ern` 1 and `examples/word_frequency.ern` 1. Found 2026-11-15 by item 11's read-back (the log's *The Flake Hunt*); the plan's MVP 4.16, item 60.
258. **`Os.closeInput` says nothing of when the hangup is made.** It answers `Unit` and is a send (E.23), so a caller that must act once the terminal is hung up cannot tell that it is. The terminal harness, `test/fixtures/pty/pty.ern`'s `hungUp`, writes nothing after it and takes the write's `Left(Closed)` for the sign. Found 2026-11-15 by item 40's read-back (the log's *The Shell's Last Line*); the plan's MVP 4.16, item 60.
259. **A spawner that waits for its child's first act writes a ready message at each site.** `spawn` promises none of the child's acts before the spawner's next (§6.2). A spawner that must not go on before one, a subscription above all, adds a `Ready` to its message type, takes `let me = self()`, has the child `send(me, Ready)` and waits in a `receive`. The form stands at 13 sites, all in the programs of test modules: `ern_terminating_tests` 5, `ern_integration_tests` 5, and one each in `ern_emitter_tests`, `ern_cli_tests` and `ern_shell_tests`. Found 2026-11-16 by item 79's read-back (the log's *Two Tests Wait for Their Subscriber*); the plan's MVP 4.16, item 60.
