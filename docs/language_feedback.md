232. **`or` inside a pattern is refused as a tuple's arity** (2026-11-04, MVP 4.2's item 4, the site's generator). `#(Paste or Load, _) ->` is refused as `a tuple has two components or more`, the help `write the component itself, or add another`, at the tuple's `#(`: `or` stands only between a clause's whole patterns, so the parser reads `Paste` as a tuple of one and stops. The message names a problem the code does not have (principle 1), which is a defect of the diagnostic: it should name the `or` and where an `or` may stand. Whether an `or` may stand inside a pattern, as Erlang's cannot and OCaml's and Rust's can, is a question of the language, which two clauses answer today.
