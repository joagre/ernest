92. **A message through an adapted address made on another node can be passed by the next one to its target** (2026-10-08, `test/peers/desk.ern`, MVP 3.0's item 8). §6.5 and §8.7 apply the function on the node that made the address, a step more, so a call sent straight after to the target can arrive first; on one node the sender applies it, and order holds. The desk sends two numbers through the store's adapted address and then asks the counter for its total, and asks again until the numbers have arrived, where the same program on one node needs one call. Where an address was made decides the order a program sees, and the text does not show where (principles 1 and 3). `nodes.md`'s section 7 weighed it and kept the step on the maker's node, since the function is the target's protocol and its captures cross untouched; the entry asks whether the order a program sees should depend on it.
