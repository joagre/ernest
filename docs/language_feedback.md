# Language feedback

What writing Ernest has felt against the principles, and what a reader found that questions a rule of the language rather than showing a defect (CLAUDE.md, *Defects and gaps*). An entry stays until a plan item decides it: a report change, an item of a milestone, or a line in the log saying it was dropped and why. An entry keeps its number, which the plan, the log and the code cite; the next is 192.

- **184**, 2026-11-01, a program started with no input: `Command(program = p, arguments = a, input = <<>>)` writes `input = <<>>` at 10 sites of the standard library's Ernest, 9 of them in `os.ern`, since E.23's `Command` has three fields and a program started with nothing to read has no shorter form. A field that says nothing at site after site, against principle 5; felt as `Os.startTerminal` was built.
- **185**, 2026-11-01, an error lifted at every call: a block whose `<-` answers `Http.ReadError` lifts each `Tcp` call's `Io.Error` with `Either.mapLeft(..., Http.Socket)`, 5 sites in `libs/http`'s three socket examples and one at every `Tcp` call of a program over the two, since a `<-` takes one error type and a library's error that wraps the host's gives a program two. Against principle 2, a second form of the one failure; felt as `libs/http` was built.
- **186**, 2026-11-01, the values every program over `Http` writes the same: `Http.Limits(line = 8192, headers = 65536)` stands at 11 sites, 9 of them `libs/http`'s doc examples and one in each of `examples/web_server.ern` and `examples/fetch.ern`, and `Http.Version(major = 1, minor = 1)` at 9, 7 of them in `http.ern`, whose own code keeps a private `version11()`. A program that speaks HTTP/1.1 within ordinary limits restates numbers and a version the library already holds. Against principle 5; felt as the two examples were written over `libs/http`.
