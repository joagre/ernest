Install

On Linux, with Erlang/OTP 29 on your PATH, GNU make and a C compiler. On Debian and Ubuntu the last two are the packages make and gcc, and OTP 29 is installed as below, since their own erlang package is older. macOS is expected to work the same way, and is not yet verified:

git clone https://github.com/joagre/ernest.git
cd ernest
make
sudo make install                  # into /usr/local
ern build examples/hello.ern
ern run examples/hello.erc         # hello, world
ern shell                          # :quit to leave
man ern                            # the toolchain; man Ernest.List for a module

OTP 29 is built from its source at erlang.org/downloads, or installed by a version manager such as kerl, where a distribution's own packages hold an older release.

Or from a release: download ern-<version>.tar.gz from the releases page, and in the directory it unpacks to run make and sudo make install, as its own README says; the archive holds the source, which make compiles, with OTP 29 as above.

Two nodes on one machine take four more commands: ern config --config-dir makes each node's directory with its key, ern config --peer-dir lists one node in the other's file, ern run --config-dir starts a node, and ern stop --config-dir ends it; the deployment guide walks through them.

make install PREFIX=$HOME/.local installs Ernest for you alone, with no sudo, where ~/.local/bin is on your PATH. make uninstall, with the same PREFIX, removes it. Without installing, the checkout's bin/ern runs in place. The Emacs mode is installed with the rest, as share/emacs/site-lisp/ernest-mode.el, and editors/emacs/README.md says how to turn it on.
