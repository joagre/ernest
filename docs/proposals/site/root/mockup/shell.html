Shell

An Ernest shell of your own, in this page, with a second node, foo, beside it.

The shell runs in the page with JavaScript. Without it, install Ernest and run ern shell.

The session

  • It ends after 5 minutes without a key. A minute before, the panel says so and offers Extend.
  • It runs in a container of its own, with 128 MB of memory and no network, and the container is removed when the session ends.
  • At most 6 sessions run at once, and an address starts at most 10 an hour; past either, the shell says it is unavailable.
  • Another tab of this browser takes the session over, and this one says so.

Privacy

No account, and one cookie, which ties this browser to its session. The panel's layout is kept in this browser and never sent. The server logs each request, your address, the time, the page asked for, its status and its size, and nothing you type.
