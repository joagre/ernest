Library

List

Since 0.1.0.

Lists: values in order, the same type throughout.

Use a list for values in an order, read from the front. For a value looked up by its key use a Map, for membership a Set, and for text a String. A list is a value: every function here answers a new list and leaves the one it was given as it was.

[] is the empty list, and x :: rest the list with x in front of rest; both are the language's, so neither is a function here.

Cost. A list is walked from its front. Putting an element in front with :: costs nothing, whatever the list's length. size, get, last and <> walk the list, and take time in proportion to its length. A list built one element at a time is built in front, and reversed once at the end.

Equality. contains and unique compare elements with ==, so the element type needs equality: a list of functions has neither.

Examples

Each element doubled, and a list appended:

List.map([1, 2, 3], fn(n) = n * 2) <> [0]
// => [2, 4, 6, 0]

The even numbers from 1 to 10, summed:

List.foldLeft(List.filter(List.range(1, 10), fn(n) = n % 2 == 0), 0, fn(sum, n) = sum + n)
// => 30

Words sorted by the order of String, and by their length:

#(List.sort(["pear", "fig", "apple"]), List.sortBy(["pear", "fig", "apple"], String.size))
// => #(["apple", "fig", "pear"], ["fig", "pear", "apple"])

See also

Map and Set for lookup by key, String.toList for the characters of a string.

List.size#

List.size(list : List(a)) : Int

The number of elements. The whole list is walked to count them.

Examples

#(List.size([1, 2, 3]), List.isEmpty([]))
// => #(3, true)

List.isEmpty#

List.isEmpty(list : List(a)) : Bool

true for the empty list.

List.contains#

List.contains(list : List(a=), element : a=) : Bool

true when some element of the list is == to element.

Examples

#(List.contains([1, 2], 2), List.contains([1, 2], 3))
// => #(true, false)

List.get#

List.get(list : List(a), index : Int) : Optional(a)

The element at index, counting from 0, or None where the list has no element there: past its end, or at an index below 0. The list is walked to the index.

Examples

#(List.get(["a", "b"], 1), List.get(["a", "b"], 2))
// => #(Some("b"), None)

List.removeAt#

List.removeAt(list : List(a), index : Int) : List(a)

Since 0.4.0.

The list without the element at index, counting from 0, as get counts. A list with no element there, past its end or at an index below 0, is answered as it was. The list is walked to the index. To remove an element by its value, filter keeps the others.

Examples

#(List.removeAt(["a", "b", "c"], 1), List.removeAt(["a", "b"], 2))
// => #(["a", "c"], ["a", "b"])

List.map#

List.map(list : List(a), f : (a) -> b receiving e) : List(b) receiving e

The list of f(x) for each element x, in order. f is called for the elements from the first.

List.filter#

List.filter(list : List(a), keep : (a) -> Bool receiving e) : List(a) receiving e

The elements keep answers true for, in their order.

Examples

List.filter([1, 2, 3, 4], fn(n) = n > 2)
// => [3, 4]

List.filterMap#

List.filterMap(list : List(a), f : (a) -> Optional(b) receiving e) : List(b) receiving e

The values f answers Some for, in order. An element f answers None for is left out, so it maps and filters in one pass.

Examples

List.filterMap(["1", "x", "3"], String.toInt)
// => [1, 3]

List.foldLeft#

List.foldLeft(list : List(a), acc : b, step : (b, a) -> b receiving e) : b receiving e

What step answers for the last element. step is called on each element in order: first with acc and the first element, then with what it answered before and the next element. The empty list answers acc.

Examples

List.foldLeft([1, 2, 3], 0, fn(sum, n) = sum + n)
// => 6

List.foldRight#

List.foldRight(list : List(a), acc : b, step : (b, a) -> b receiving e) : b receiving e

The elements folded into one value, from the last. step(acc, x) is called with the given acc for the last element, and with what step answered for the one after it for the rest. The accumulator comes first, as in foldLeft. The empty list answers acc.

Examples

List.foldRight(["a", "b"], "", fn(acc, text) = text <> acc)
// => "ab"

List.mapFold#

List.mapFold(list : List(a), acc : b, step : (b, a) -> #(b, c) receiving e) : #(b, List(c)) receiving e

Since 0.5.0.

The accumulator after the last element, and the list of what step maps each element to, in order. step(acc, x) answers #(next, y): the accumulator for the element after x, and what x maps to. It is called on each element in order, as in foldLeft, first with the given acc. The empty list answers #(acc, []).

Examples

List.mapFold([1, 2, 3], 0, fn(sum, n) = #(sum + n, sum))
// => #(6, [0, 1, 3])

List.forEach#

List.forEach(list : List(a), f : (a) -> Unit receiving e) : Unit receiving e

Since 0.4.0.

Calls f for each element, in order, for its effect, and answers Unit.

Examples

Prints 1 and 2, each on a line:

List.forEach([1, 2], fn(n) = Io.println(Int.toString(n)))
// => Unit

List.any#

List.any(list : List(a), test : (a) -> Bool receiving e) : Bool receiving e

true when test holds for at least one element, and false for the empty list. test is not called after the first element it holds for.

Examples

#(List.any([1, 2], fn(n) = n > 1), List.all([1, 2], fn(n) = n > 1))
// => #(true, false)

List.all#

List.all(list : List(a), test : (a) -> Bool receiving e) : Bool receiving e

true when test holds for every element, and for the empty list. test is not called after the first element it fails for.

List.find#

List.find(list : List(a), test : (a) -> Bool receiving e) : Optional(a) receiving e

The first element test holds for, or None where there is none.

Examples

List.find([1, 2, 3], fn(n) = n > 1)
// => Some(2)

List.last#

List.last(list : List(a)) : Optional(a)

The last element, or None for the empty list. The whole list is walked to reach it.

Examples

The empty list needs its element type written, since nothing else settles it:

{
    let empty : List(Int) = [];
    #(List.last([1, 2]), List.last(empty))
}
// => #(Some(2), None)

List.take#

List.take(list : List(a), count : Int) : List(a)

The first count elements, or all of them where there are fewer. A count below 0 takes none.

Examples

#(List.take([1, 2, 3], 2), List.drop([1, 2, 3], 2))
// => #([1, 2], [3])

List.drop#

List.drop(list : List(a), count : Int) : List(a)

The list without its first count elements, or empty where there are fewer. A count below 0 drops none.

List.takeLast#

List.takeLast(list : List(a), count : Int) : List(a)

Since 0.4.0.

The last count elements, or all of them where there are fewer. A count below 0 takes none. The whole list is walked to find them.

Examples

#(List.takeLast([1, 2, 3], 2), List.takeLast([1, 2, 3], 5))
// => #([2, 3], [1, 2, 3])

List.dropLast#

List.dropLast(list : List(a), count : Int) : List(a)

The list without its last count elements, or empty where there are fewer. A count below 0 drops none.

Examples

#(List.dropLast([1, 2, 3], 1), List.dropLast([1, 2, 3], 5))
// => #([1, 2], [])

List.span#

List.span(list : List(a), test : (a) -> Bool receiving e) : #(List(a), List(a)) receiving e

The list split where test first fails: the elements before that one, all of which test holds for, and the rest, from that one on.

Examples

List.span([1, 2, 3, 1], fn(n) = n < 3)
// => #([1, 2], [3, 1])

List.partition#

List.partition(list : List(a), test : (a) -> Bool receiving e) : #(List(a), List(a)) receiving e

The elements test holds for, and those it does not, each in their order.

Examples

List.partition([1, 2, 3, 4], fn(n) = n % 2 == 0)
// => #([2, 4], [1, 3])

List.unique#

List.unique(list : List(a=)) : List(a=)

The list without repeats: the first occurrence of each element is kept, in order.

Examples

List.unique([2, 1, 2, 3])
// => [2, 1, 3]

List.indexed#

List.indexed(list : List(a)) : List(#(Int, a))

Each element paired with its index, counting from 0.

Examples

List.indexed(["a", "b"])
// => [#(0, "a"), #(1, "b")]

List.repeat#

List.repeat(element : a, count : Int) : List(a)

A list of count copies of element. A count below 0 gives the empty list.

Examples

List.repeat("ha", 2)
// => ["ha", "ha"]

List.reverse#

List.reverse(list : List(a)) : List(a)

The elements in the opposite order.

Examples

List.reverse([1, 2, 3])
// => [3, 2, 1]

List.sort#

List.sort(list : List(a)) : List(a) needs a.compare

The elements sorted by the order of their type, the least first (report §3.10).

The sort is stable: two elements compare calls Equal keep the order they had. Another order is a key, which sortBy sorts by.

Examples

List.sort([3, 1, 2])
// => [1, 2, 3]

List.sortBy#

List.sortBy(list : List(a), key : (a) -> k receiving e) : List(a) receiving e needs k.compare

Since 0.5.0.

The elements sorted by their key, the least first by the order of the key's type (report §3.10). key is called once for each element, in order.

The sort is stable: two elements whose keys compare calls Equal keep the order they had. A key that is a tuple orders by its first component, and by the next among equals; one that is a number made negative orders the greatest first.

Examples

The words by their length, and the longest first, the order of String among equal lengths:

#(List.sortBy(["pear", "fig", "kiwi"], String.size),
  List.sortBy(["pear", "fig", "kiwi"], fn(word) = #(-String.size(word), word)))
// => #(["fig", "pear", "kiwi"], ["kiwi", "pear", "fig"])

List.minimumBy#

List.minimumBy(list : List(a), key : (a) -> k receiving e) : Optional(a) receiving e needs k.compare

Since 0.4.0.

The element whose key is the least by the key type's compare, or None for the empty list. Of elements whose keys compare calls Equal, the first is answered. key is called once for each element, in order.

Examples

The shortest word, and the first of the two longest:

#(List.minimumBy(["pear", "fig", "kiwi"], String.size),
  List.maximumBy(["pear", "fig", "kiwi"], String.size))
// => #(Some("fig"), Some("pear"))

List.maximumBy#

List.maximumBy(list : List(a), key : (a) -> k receiving e) : Optional(a) receiving e needs k.compare

Since 0.4.0.

The element whose key is the greatest by the key type's compare, or None for the empty list. Of elements whose keys compare calls Equal, the first is answered. key is called once for each element, in order.

List.zip#

List.zip(list : List(a), other : List(b)) : List(#(a, b))

The pairs of the elements at each index of both lists. The longer list's extra elements are left out.

Examples

List.zip([1, 2, 3], ["a", "b"])
// => [#(1, "a"), #(2, "b")]

List.unzip#

List.unzip(pairs : List(#(a, b))) : #(List(a), List(b))

The pairs taken apart: the list of their first components and the list of their second, each in order.

Examples

List.unzip([#(1, "a"), #(2, "b")])
// => #([1, 2], ["a", "b"])

List.flatMap#

List.flatMap(list : List(a), f : (a) -> List(b) receiving e) : List(b) receiving e

The lists f answers for the elements, joined in order.

Examples

List.flatMap([1, 2], fn(n) = [n, n * 10])
// => [1, 10, 2, 20]

List.range#

List.range(first : Int, last : Int) : List(Int)

The integers from first to last, both included, counting up. Where first is greater than last the list is empty.

Examples

#(List.range(1, 4), List.range(2, 1))
// => #([1, 2, 3, 4], [])

List.tryMap#

List.tryMap(list : List(a), step : (a) -> Either(e, b) receiving x) : Either(e, List(b)) receiving x

Calls step on each element in order. Where every call answers Right(y), the answer is Right of the list of the ys. At the first Left(e) the answer is Left(e), and step is not called again. The empty list answers Right([]).

Examples

List.tryMap(["1", "x"], fn(s) = Either.fromOptional(String.toInt(s), s))
// => Left("x")

List.tryFold#

List.tryFold(list : List(a), acc : b, step : (b, a) -> Either(e, b) receiving x) : Either(e, b) receiving x

Folds the list as foldLeft does, step answering Right of the next accumulator. Where every call answers a Right, the answer is Right of the last accumulator. At the first Left(e) the answer is Left(e), and step is not called again. The empty list answers Right(acc).

Examples

List.tryFold([1, 2], 0, fn(acc, n) = if n > 1 then Left("big") else Right(acc + n))
// => Left("big")

List.compare#

compare(left, right) : Ordering needs a.compare

Since 0.5.0.

The order of two lists: element by element from the first, by the element type's compare, and a list before a longer one it begins (report §3.10). < and the other comparisons of two lists read it.

Examples

#(compare([1, 2], [1, 3]), [1, 2] < [1, 2, 0], ["b"] > ["a", "z"])
// => #(Less, true, true)

List.<>#

list <> other : List(a)

The elements of the first list, then those of the second. The first list is copied, so the cost grows with its length, and not with the second's.

Examples

[1, 2] <> [3]
// => [1, 2, 3]
