## A Digest in Lower Case, 2026-11-22

MVP 4.6's item 6, feedback 273, decided with the user on the session's recommendation: `Bytes.toHex` writes lower-case letters (E.20), and `fromHex` reads either case as before.

**What the reading found.** The plan named `Uri`'s percent-encoding as the site that needs upper case. `Uri` writes none: it reads one, in either case, and `Http`'s `target` writes its escapes from a table of its own (G.11). The form that needs upper case is `\xHH`, which a refusal writes for a control character (§11) and ernest-httpd's access log writes too. Three sites lowercased what `toHex` wrote, `Ernest.Unpack`'s digest, `tools/site.ern`'s and ernest-httpd's session cookie, so the second step moves from three sites to two.

**The reason.** That most languages write lower case is no reason: principle 1's reader knows Ernest and Erlang and no other language, and predicts upper case from `Int.toStringBase` (E.8), from `\xHH` and from `binary:encode_hex/1`. What decides is how each case fails. A digest in the wrong case fails silently: `Bytes.toHex(Crypto.sha256(bytes)) == "e3b0…"` is `False` and says nothing, where a manifest's `sha256` is lowercase by §11.9's own rule, as `sha256sum` and git write one. A `\xHH` in the wrong case is seen by the one who writes it and still reads right. The resulting code decides (§0's principle 1), and the silent `False` falls on the commonest use.

**What it costs.** `Bytes.toHex` and `Int.toStringBase` now differ in case, and E.20's line states it. `Int.toStringBase` stays: no program asks, and the host writes upper case there, so lower case would be a second pass over its text. `toHex` is a shim, `ern_bytes:to_hex/1`, over `binary:encode_hex/2`, since a foreign name passes no atom.

**Set aside.** A second function beside `toHex`, which E.0's shape rule 3 refuses: a conversion exists once. A case as an argument, which every site would write. Upper case kept and the entry dropped, with `Crypto`'s examples comparing through `Bytes.fromHex`: the trap stays for whoever compares text.

**The applications.** At its next floor ernest-httpd's cookie drops its step, its access log gains `String.toAsciiUpper` and its `WebSocket` examples change their letters. That is its own session's work.
