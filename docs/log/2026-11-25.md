# The decisions log, 2026-11-25

## The First Build of Leg 4, 2026-11-25

The report is written from `cold3/v5/` in one commit with the code that makes its tests pass, as *The Answers Read Cold's Six* had it. With the copy in place `make test` failed the four tests named there and no other. The build was one agent's, on Opus 5.5 at xhigh, from the brief beside the copy.

**The computes' names.** The two computes took each other's names. `Peer.compute(name, f, ms)` runs on the peer named, as `Peer.spawn(name, f, ms)` does, and `Peer.computeAnywhere(f, ms)` runs on the peer the node picks. The host functions behind them follow, `ern_peer:compute/3,4` and `compute_anywhere/2,3`, and so do the checker's helps, the guide, the tour and the bench. The bench's rounds are `compute_named` and `compute_anywhere`, so that no old label stands for the other compute.

**`Io.debug`.** It is a function of `io.ern` under `needs a.show`, which prints `Io.show`'s text and a line feed on standard error and answers the value. What the checker, the emitter and the runtime did for it as a primitive is gone. At a type not known whole its refusal is the one every requirement's `show` has, `Io.debug needs Optional(a).show, and Io.show writes a type known whole, or a requirement's type variable`, and each such refusal now carries `Io.show`'s help to annotate, as E.1 says. Feedback 278 names `Io.show`'s declaration alone.

**`NotLoaded(String)`.** The value carries the words the peer writes after `was not loaded:`, built in one place, `ern_peer:lacking/1`, so one cause has one text on both nodes. The shell writes them after `could not load the shell:`. A nodes test makes a release without `ern_shell` and attaches to it, which closes the known issue that no test ran that refusal. A compute's failure text is now read as a spawn's is: one that is not UTF-8 answers `Other("the peer's answer could not be read")`, as E.27 says of an answer the caller's node cannot read, where before a compute passed any failure through.

**`Int.toStringBase`.** It answers `String` and faults with `a base is from 2 to 36`. The four sites that matched its `None` lose the clause, the shell's helper among them, and feedback 276, which this decides, is removed.
