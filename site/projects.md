# Projects

These are libraries and programs written in Ernest, each in a repository of its own, and none is installed with Ernest. A project's README says the release of Ernest it builds on.

- [ernest-epx](https://github.com/joagre/ernest-epx): A 2-D library of pixmaps and their pixels over epx, the pixel library for Erlang, with a window that shows a pixmap on the screen.
- [ernest-httpd](https://github.com/joagre/ernest-httpd): The web server of ernest-lang.org, which serves its pages and connects a terminal in each visitor's browser to a shell on the server.
