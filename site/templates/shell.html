Shell

This page runs an Ernest shell of your own and a second node named foo beside it.

The shell runs in the page with JavaScript. Without it, install Ernest and run ern shell.

The session

  • It ends after a while without a key. The panel says so shortly before and offers Extend.
  • It runs in a container of its own, with no network. The container is removed when the session ends.
  • At most a few sessions run at once, and one address starts at most a few in a while. Past either limit the shell says it is unavailable.
  • Another tab of this browser takes the session over, and this one says so.
  • F6 leaves the terminal.

Privacy

There is no account. One cookie ties this browser to its session. The panel's layout is kept in this browser and never sent. The server logs each request: your address, the time, the page asked for, its status and its size. It logs nothing you type.
